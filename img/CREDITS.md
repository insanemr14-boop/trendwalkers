## Note on the Unsplash photographer names

The four Unsplash images are identified only by their CDN asset ID
(`photo-<id>`), which is not the same identifier as the public photo-page slug.
The Unsplash search API requires an API key that is not available in this
environment, and `unsplash.com/photos/photo-<id>` returns 404, so the
contributor names could not be resolved without guessing. They are recorded as
undetermined rather than attributed incorrectly.

The Unsplash Licence does not require attribution, so this does not affect the
right to use these images commercially. If the names are wanted later, paste
each source URL into a browser and use Unsplash's reverse lookup, or resolve
them via the Unsplash API with a registered application key.
